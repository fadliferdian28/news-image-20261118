One day of world news as a stack of newspapers: 40 verified stories from Wednesday 18 November 2026 on a single 1024×1024 front page. The main sheet carries the full front page — navy masthead, 7-region bar, day-in-numbers strip, 13 cards with CLAIM/CONFIRMED proof tags, a 27-story tail, a dotted world map and a DATE CHECK naming the traps the field got wrong. Three background sheets peek out from behind it (The Sunday Globe, The Daily World, Morning Herald — invented names), each with one AI-generated scene and headlines from the same verified story set. Every story happened or was first reported on 18 November 2026; the numbers strip (141 / 126 / 25.9bn km / 535 halted / 251–11 / $83) is trap-free.

## Run it

```sh
python3 main.py
```

This regenerates `entry.png` deterministically (byte-identical on every run) and prints the bounding-box overlap check: background-sheet elements must never overlap main-sheet text.
